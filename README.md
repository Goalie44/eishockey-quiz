# Eishockey-Quiz (EHC-Nachwuchs)

Animiertes Quiz zu Spielsituationen und Regelkunde – mit Login pro Spieler und Trainerbereich.

- `index.html` – die komplette App (Login, Quiz, Trainerbereich)
- `config.js` – Supabase-URL und anon key (leer = Demo-Modus)
- `setup.sql` – einmalig im Supabase SQL Editor ausführen
- `src/` – Quelldateien, aus denen `index.html` zusammengebaut wird

Hosting: GitHub Pages (Settings → Pages → Branch `main`, Ordner `/`).
